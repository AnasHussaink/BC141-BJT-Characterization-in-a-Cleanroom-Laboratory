# Measurement data

The participant reports that original data and a lab report are available. They have not yet been incorporated here. There are no fabricated or simulated measurement datasets in this folder.

Useful files include EasyEXPERT exports, CSV/XLS/XLSX tables, original instrument project/result files, and the lab report. Preserve native files alongside any converted tables.

For each dataset, recover:

- Device model and specimen ID.
- Test/configuration name, common terminal, terminal assignments and sign convention.
- Swept variable, range, step, direction and stepped bias condition.
- Measured quantities and units.
- Compliance limits/status flags, ranges, integration/settling settings if available.
- Session conditions, including date and temperature when recorded.

Do not infer these values from generic handout settings or photo filenames. Keep unnecessary personal or laboratory-access details out of a public data release.
